# RebateTool 介绍网站

个人开发、个人自用的 Windows PC 客户端项目介绍页。软件 v0.1.1，测试阶段；截至 2026-10-27，真实 CPS 生产渠道为 0。本站不代表任何购物平台认证，不提供在线交易、收益承诺、广告或付费功能。

本仓库仅包含经过审查的静态网站，不含 RebateTool 桌面软件完整源码、EXE、数据库、凭据、订单或个人信息。

直接打开 `index.html`，或使用 Python 在此目录运行 `python -m http.server 8765 --bind 127.0.0.1` 预览。无需构建、Node.js、付费 API 或外部字体服务。GitHub Pages 从 main 分支根目录发布，使用 GitHub 提供的 HTTPS 域名。
